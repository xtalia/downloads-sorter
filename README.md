# Downloads Sorter — сортировка файлов по папкам

Нативные скрипты для **Windows XP и новее**, **Windows 10–11**, **Linux** и **macOS**.
Без установки Python, Node.js или сторонних модулей. Расширения сравниваются без учёта регистра: `.jpg`, `.JPG` и `.JpG` обрабатываются одинаково.

## Скачать

[Последний релиз](https://github.com/xtalia/downloads-sorter/releases/latest) содержит **три ZIP-архива**:

| Архив | Что внутри | Требования |
|---|---|---|
| `downloads-sorter-windows-v1.0.0.zip` | `sort-downloads.bat` + `.ps1` (современный); `sort-downloads-legacy.bat` + `.js` (старый) | Windows 10–11: Windows PowerShell 5.1. XP+: включённый Windows Script Host / JScript |
| `downloads-sorter-linux-v1.0.0.zip` | `sort-downloads.sh` | Bash 3.2+ и стандартные утилиты `mv`, `mkdir`, `tr`, `cat` |
| `downloads-sorter-macos-v1.0.0.zip` | `Sort Downloads.command` | Системный `/bin/bash` 3.2+ и стандартные утилиты macOS |

Распакуй **весь** архив: файл `categories.txt` должен лежать рядом со скриптом.
В клоне репозитория скрипты находятся в подпапках `windows/`, `linux/`, `macos/`; в ZIP они лежат в корне.

## Безопасность и поведение

- **По умолчанию только предпросмотр** (`PLAN`). Перемещение включается **только флагом `--apply`**.
- Без `--path` обрабатывается **папка самого скрипта**, а не текущая рабочая директория и не автоматически системная «Загрузки». Чтобы разобрать «Загрузки», укажи её путь или положи туда файлы скрипта.
- Только файлы верхнего уровня. Подпапки, включая `.app`-пакеты macOS, не перемещаются и не обходятся.
- Все восемь папок создаются **по необходимости**, только при реальном перемещении.
- Если файл с таким именем уже есть в папке назначения, выводится `SKIP`: **оба файла остаются без изменений**. Автопереименования нет.
- Ничего не удаляется. `.torrent`, `.magnet`, неизвестные расширения, файлы без расширения, `.part`, `.crdownload` и `.download` остаются на месте.
- Симлинки/Windows reparse points среди файлов пропускаются. Категория, являющаяся симлинком, junction или обычным файлом, даёт ошибку и не используется.
- Имена с пробелами, кириллицей, `&`, скобками и `!` не интерпретируются как команды. Содержимое файлов не читается и не меняется.
- Файлы самого инструмента защищены от перемещения по имени (без учёта регистра): `sort-downloads.bat`, `.ps1`, `sort-downloads-legacy.bat`, `.js`, `sort-downloads.sh`, `Sort Downloads.command`, `categories.txt`, `README.md`, `LICENSE`. Также защищён текущий файл выполняемого скрипта, даже если его переименовали.
- При наличии `--apply` и `--dry-run` действует **последний** из этих флагов.
- Итог: `Planned` — кандидаты без уже существующей цели, `Moved` — реально перемещённые, `Errors` — ошибки. В режиме предпросмотра `Moved=0`.

**Ограничения:** это не демон и не транзакционная система. Не запускай несколько экземпляров одновременно; не меняй папки/симлинки параллельно со скриптом. При ошибке предыдущие успешные перемещения не откатываются. Активно скачиваемый файл с уже окончательным расширением определить невозможно — сначала дождись окончания загрузок. Скрытые обычные файлы с известным расширением тоже сортируются. Сетевые диски, очень длинные пути и разрешения зависят от ОС; для XP действует обычное ограничение Win32 на длину пути. Первый запуск лучше сделать на копии.

## Windows 10–11

Открой **cmd.exe** в папке распакованного архива:

```bat
sort-downloads.bat --path "%USERPROFILE%\Downloads"
sort-downloads.bat --path "%USERPROFILE%\Downloads" --apply
```

Можно вызвать PowerShell-ядро напрямую (например, из PowerShell):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\sort-downloads.ps1 --path "$HOME\Downloads" --apply
```

`ExecutionPolicy Bypass` действует только на этот процесс и не меняет системную политику. Администраторские права не нужны. Двойной щелчок по BAT показывает **предпросмотр своей папки** и ждёт нажатия клавиши; для перемещения используй `--apply` в командной строке.

## Windows XP и новее

```bat
sort-downloads-legacy.bat --path "C:\Documents and Settings\User\Downloads"
sort-downloads-legacy.bat --path "C:\Documents and Settings\User\Downloads" --apply
```

Путь — пример; на XP стандартной папки Downloads может не быть. Используется штатный `cscript.exe` и ES3/JScript + `Scripting.FileSystemObject`, **без PowerShell**. Если Windows Script Host запрещён политикой безопасности, legacy-вариант не запустится; не отключай корпоративную защиту ради скрипта.

## Linux

```bash
bash ./sort-downloads.sh --path "$HOME/Downloads"
bash ./sort-downloads.sh --path "$HOME/Downloads" --apply
```

Для прямого запуска: `chmod +x sort-downloads.sh`, затем `./sort-downloads.sh ...`. В дистрибутивах без Bash сначала нужен Bash; `/bin/sh` не подходит. Для локализованной папки укажи фактический путь.

## macOS

```bash
chmod +x "Sort Downloads.command"
./"Sort Downloads.command" --path "$HOME/Downloads"
./"Sort Downloads.command" --path "$HOME/Downloads" --apply
```

Двойной щелчок по `.command` открывает Terminal и показывает **только предпросмотр папки скрипта**. Для перемещения используй команду с `--apply`. Если macOS блокирует скачанный файл, проверь источник и используй системное «Открыть»/«Конфиденциальность и безопасность»; не отключай Gatekeeper глобально. Для Terminal может потребоваться разрешение на доступ к «Загрузкам».

## Категории

Единая таблица `categories.txt` в каждом комплекте, формат: `категория расширение расширение ...`.
Имена категорий — только строчные ASCII-буквы, расширения — ASCII-буквы и цифры; без точек и дублей. Если редактируешь таблицу, сохрани ASCII/UTF-8 **без BOM**, с окончаниями строк **LF**. Не удаляй таблицу.

| Папка | Примеры |
|---|---|
| `archives` | ZIP, RAR, 7Z, TAR.GZ, ZST |
| `iso` | ISO, IMG, BIN, DMG, VHD, QCOW2 |
| `music` | MP3, FLAC, WAV, M4A, OPUS, M3U |
| `video` | MP4, MOV, MKV, WEBM, M2TS |
| `programs` | EXE, MSI, APK, DEB, RPM, BAT, PS1, SH, COMMAND |
| `photos` | JPG, JPEG, HEIC, HEIF, TIFF, DNG, CR2/CR3, NEF, RAW |
| `images` | PNG, GIF, SVG, WEBP, AVIF, JXL, PSD |
| `docs` | PDF, DOCX, XLSX, TXT, EPUB, FB2, MD, CSV |

`.dmg` однозначно относится к `iso`, `.tif`/`.tiff` — к `photos` (в исходном BAT были пересечения). Используется последнее расширение: `archive.tar.gz` → `archives`. Тип определяется по имени, не по содержимому.

## Исходный референс

`reference/original.bat` — **побайтовая копия** исходника пользователя (Windows-1251, оригинальные окончания строк). `reference/original-readable.txt` — читаемая UTF-8-копия.

**Не запускай референс для обычной сортировки:** он удаляет `.torrent`/`.magnet` и не содержит новых защит. В релизные архивы он намеренно не включён.

## Разработка и проверки

Для тестов и упаковки нужен только Python 3.12+ (конечному пользователю Python не нужен):

```bash
# Linux
SORTER_VARIANT=linux python -m unittest discover -s tests -v
# macOS: SORTER_VARIANT=macos
# Windows PowerShell:
# $env:SORTER_VARIANT='modern'  # либо legacy
# python -m unittest discover -s tests -v
python tools/build_release.py --version 1.0.0
```

CI запускает реальные интерпретаторы на Windows, Ubuntu и macOS (системный Bash 3.2), тестирует предпросмотр, категории, регистр, Unicode, коллизии, повторный запуск, симлинки/junction, аргументы, содержимое ZIP и SHA-256. Также выполняется smoke-тест скриптов **после распаковки** релизного ZIP.

Legacy-совместимость рассчитана на API и синтаксис XP; **реальный Windows XP не тестировался**. Автотесты legacy выполняются через WSH на современном Windows. Не следует считать это сертификацией для каждой старой версии Windows.

При push тега `vMAJOR.MINOR.PATCH` CI после тестов собирает три ZIP и создаёт **черновик** релиза. Публикуй его только после проверки скачанных архивов и SHA-256.

Коды завершения: **0** — успешная обработка/предпросмотр (коллизии не считаются ошибкой); **1** — ошибки отдельных перемещений/категорий; **2** — неверные аргументы, таблица или корневая папка.
